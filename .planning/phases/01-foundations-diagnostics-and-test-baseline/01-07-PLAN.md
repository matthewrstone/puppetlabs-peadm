<interfaces>
Contract this plan creates (Phase 2 preflight BLOCK/WARN and Phase 5 CD4PE/SCM plans consume it, D-06):

```ruby
module PeadmCertCheck
  # Returns an OpenSSL::PKey::PKey for PEM or DER RSA, EC or Ed25519 data. Raises OpenSSL::PKey::PKeyError.
  def self.load_key(data, passphrase = nil)
  # Returns { 'severity' => 'error'|'warn', 'code' => String, 'message' => String, 'path' => String|nil }
  def self.finding(severity, code, message, path = nil)
  # Reads the files, runs every applicable check, returns Array of finding hashes (empty = clean).
  def self.check(cert_path:, key_path: nil, chain_path: nil, crl_path: nil, warn_days: 30, key_passphrase: nil, now: Time.now)
end
```

Finding codes (stable; add new codes rather than renaming): `cert_unreadable`, `cert_parse_error`, `cert_expired` (error), `cert_expires_soon` (warn), `cert_not_yet_valid` (error), `cert_empty_subject` (error), `key_unreadable`, `key_parse_error`, `key_encrypted` (error, passphrase needed), `key_mismatch` (error), `chain_unverified` (error, message carries `store.error_string`), `crl_bad_header` (error), `crl_parse_error` (error), `crl_stale` (warn, next_update in the past), `crl_issuer_mismatch` (warn), `cert_revoked` (error).

Task output on STDOUT: `{"ok": <no error findings>, "findings": [...]}`; exit 0 whenever the checks ran (the caller decides to fail or warn, D-06); a usage error (no cert_path, unreadable params JSON) prints `{"_error": {"msg": ..., "kind": "peadm/validate_cert-usage"}}` and exits 1.
